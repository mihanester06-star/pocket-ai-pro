# Pocket AI — автосканер без OTC (дослідницький прототип)

Вебінтерфейс Streamlit, адаптований до Safari на iPhone і комп'ютерів. Автосканер паралельно перевіряє вбудований перелік звичайних Forex, crypto, акцій, індексів і товарів, сортує кандидатів, відхиляє застарілі дані, дозволяє завантажити результати CSV. Також збережені ручний аналіз, новинні заголовки, журнал та калькулятор перекриттів.

## Запуск

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

Для доступу з iPhone розгорніть проєкт на власному сервері чи Streamlit Community Cloud з HTTPS; просто відкриття ZIP на iPhone не запускає сайт. Не публікуйте локальну базу даних з приватними даними.

## Чесні обмеження

- Це НЕ повний підтверджений каталог Pocket Option і НЕ інтеграція з платформою. Інструменти без назви OTC не гарантують наявності на Pocket Option.
- Ціни надходять від Yahoo Finance, можуть запізнюватися та відрізнятися від котирувань Pocket Option.
- Показаний бал ML не калібрований; 70–80% точності не доведено. Короткий holdout-тест не є повноцінним walk-forward тестом.
- RSS-новини показані лише для ознайомлення, модель їх не читає; економічний календар ще не інтегрований.
- Автосканер запускається натисканням кнопки, не працює цілодобово у фоні. Журнал перевіряється лише коли вручну аналізується конкретний ticker; сканер не відкриває угод.
- Перекриття — тільки калькулятор ризику. Мартингейл не покращує якість прогнозу і може призвести до великих втрат.
- Не використовуйте результати для реальної торгівлі без незалежної перевірки й тривалого демотестування.


## Streamlit Community Cloud — запуск

1. Створіть GitHub репозиторій без паролів, ключів та приватних даних.
2. Завантажте `app.py`, `requirements.txt`, `.streamlit/config.toml`, `.gitignore` і `README.md` у корінь репозиторію.
3. У Streamlit Community Cloud виберіть публічний репозиторій, гілку `main`, головний файл `app.py`.
4. Якщо виникають помилки, перегляньте логи збірки.

**Примітка:** застосунок не торгує автоматично, не підключений до Pocket Option, не гарантує прибутку. Yahoo Finance може обмежувати запити; масове сканування інколи триває довго або завершується частковими помилками. SQLite на безкоштовному хостингу не є постійним сховищем.
